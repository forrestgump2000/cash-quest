# Cash Quest 💰

A first-person 3D treasure hunting game. Explore, find valuable items, sell them at the **$ station**, and upgrade your gear.

- **Locations:** Junkyard (start) → Beach → City → Abandoned Warehouse → Museum
- **Gear:** metal detectors (dig up buried loot), scanners (radar), flashlights, backpacks, shoes
- **Luck:** permanent lucky charms and temporary luck potions boost your odds of rare finds

## Controls
WASD move · Mouse look · **E** interact / dig / shop · **F** flashlight · **Shift** sprint · **Esc** pause.
Touch devices get an on-screen joystick and buttons.

## Develop
```bash
npm install
npm run dev
```

Built with [Three.js](https://threejs.org) and Vite. Progress is saved in your browser.
Icon and thumbnail sources live in `art/`.
